How Groundwork RAG Works

A production-grade, zero-embedding-cost Agentic QA architecture built with FastAPI, Qdrant Hybrid Search, Groq Llama 3.1 Generator, and OpenAI GPT-4o-mini Critic Judge.

1

Multi-Doc Ingestion & OCR

Extracts body text, parsed tables (as Markdown), and embedded figures/images. Implements robust OCR fallbacks (pytesseract+pdf2image) for image-only scanned files.

2

Multimodal Vision & 4-Strategy Chunking

Embedded charts/figures described via GPT-4o-mini Vision (Groq fallback). Chunks routed via 4 strategies: Table-Atomic, Image-Atomic, Section-Aware (headings), or Semantic (SentenceTransformers).

3

Zero-Cost Hybrid Retrieval

Combines local dense vectors (all-MiniLM-L6-v2) and BM25 sparse weights fused via Qdrant's server-side Reciprocal Rank Fusion (RRF).

4

Cross-Encoder & Relevance Gate

Reranks top candidates with ms-marco-MiniLM-L-6-v2. Out-of-domain queries failing the 0.001 sigmoid threshold are immediately refused to save 100% of LLM costs.

5

Critic Guardrail & Confidence Score

OpenAI gpt-4o-mini inspects response grounding (1 retry limit). Computes a weighted 0-1 confidence score based on grounding verdict, rerank relevance, and retry count.
